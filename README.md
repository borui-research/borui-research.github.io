# Bo Rui Academic Personal Website

This is a lightweight GitHub Pages-ready academic homepage inspired by Ph.D. student personal sites.

## Files

- `index.html`: main website content.
- `styles.css`: visual design and responsive layout.
- `files/cv.pdf`: public CV linked from the homepage.
- `assets/`: place your profile photo here if you want to replace the initials portrait.

## How to publish on GitHub Pages

1. Create a public GitHub repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload these files to the repository root.
3. In GitHub, open `Settings > Pages`.
4. Set the source to `Deploy from a branch`, branch `main`, folder `/root`.
5. Your site will be available at `https://YOUR_GITHUB_USERNAME.github.io/`.
